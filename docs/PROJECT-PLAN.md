# EKSA VPN

A secure VPN application project.

## Project Components

- Android App (Kotlin)
- Backend API (Python FastAPI)
- Admin Panel (Bengali and English)
- PostgreSQL Database
- WireGuard VPN Server

## Server Locations

- Saudi Arabia
- Europe

## Supported Mobile Networks

- STC
- Mobily
- Zain

SIM-based features will use operator-approved connectivity and data plans.

## Main Features

- User Registration and Login
- Free and Premium Plans
- VPN Server Selection
- One Tap Connect
- Subscription Management
- Admin Dashboard
- User Management
- Server Monitoring

## Security

- Secure authentication
- Encrypted VPN connections
- Protected user information
- No hardcoded passwords or private keys

Project setup in progress.
